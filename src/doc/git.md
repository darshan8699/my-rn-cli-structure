# Upload folder to GitHub repo:

==============
Step 1: Initialize Git in your project folder (if not already a git repo)
git init

Step 2: Stage all your files
git add .

Step 3: Commit the changes
git commit -m "Initial commit"

Step 4: Rename default branch to main
git branch -M main

Step 5: Link your local repository to GitHub
git remote add origin https://github.com/darshan8699/my-rn-cli-structure.git

Step 6: Push your code to GitHub
git push -u origin main

==============

# Future Updates (Whenever you make new code changes):

==============
Stage modified files:
git add .

Commit changes with a message:
git commit -m "Add new feature / fix bug"

Push to GitHub:
git push
